# 課題6-1：試行単位の5分割交差検証

## 結果

各Foldで各動作の同番号の試行を評価用とし、残りの試行で標準化とロジスティック回帰の学習を行った。特徴量は第5回と同じ標準偏差・最大値を用いた。Fold別Accuracyとその平均・標準偏差は同梱のCSVに記載した。

| Fold | Accuracy |
| --- | ---: |
| 1 | 79.37% |
| 2 | 86.89% |
| 3 | 81.54% |
| 4 | 94.29% |
| 5 | 90.28% |

5 Foldの単純平均は86.47%、標準偏差は5.49パーセントポイント（ddof=0）だった。第5回の固定分割では、今回のFold 5と同じ試行を評価に使い、Accuracyは90.28%だった。第5回の5-1は標準化なし、5-2の標準化ありは今回と同じ処理である。

## 前回1回のAccuracyは代表的だったか

第5回のAccuracy（90.28%）だけでは、評価する試行によって79.37%から94.29%まで変わるという、分割によるばらつきの大きさが伝わらない。また、第5回の値は5分割の平均（86.47%）より約3.81パーセントポイント高いため、それをモデルの代表値とすると、今回のデータにおける平均的な性能を高めに見積もってしまう。
