# 課題5-4

## 追加特徴量の意図と事前予想

FFTピーク周波数は強い繰り返し成分を捉え、jumpの分類に役立ちそうだと予想する。
平均は窓全体の合成加速度の大きさを捉え、追加するとwalkとjumpの分類精度が少し向上しそうだと予想する。

## 結果と考察

| 条件 | 特徴量 | 評価用の正解数 | 評価用Accuracy |
| --- | --- | --- | --- |
| A | 標準偏差・最大値 | 65/72 | 90.28% |
| B | 標準偏差・最大値・平均・FFTピーク周波数 | 68/72 | 94.44% |

| 動作 | Aの正解数 | Bの正解数 |
| --- | --- | --- |
| walk | 21/22 | 20/22 |
| jump | 24/30 | 28/30 |
| squat | 20/20 | 20/20 |

平均とFFTピーク周波数を追加したことで、jumpの正解数は24/30から28/30に増加し、識別精度が向上した。
ただし、2特徴量を同時に追加しているため、FFTと平均がそれぞれどの程度影響したかは、この比較だけでは判断できない。
walkの正解数は少し減少したものの、全体のAccuracyは90.28%から94.44%に改善したため、今回の条件ではおおむね有効な特徴量選択だったと考える。
