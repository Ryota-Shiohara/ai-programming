# 第2回の提出物

提出するファイルは以下の6つです。課題番号に合わせて命名しています。

| 課題 | 提出ファイル | 内容 |
| --- | --- | --- |
| 2-1 | `2-1.zip` | スクリーンショット8枚をZIP直下に保存（フォルダ分け・READMEなし）。GPSは任意のため未収録。 |
| 2-2 | `2-2.zip` | walk・jump・squat各5試行の元CSV（計15個）と計測条件のテキスト。 |

`2-1/` と `2-4/` はZIP作成元として残しています。提出時には上記のファイルを選んでください。

課題2-5（ボーナス）の提出用データも作成済みです。

## プログラムの実行

リポジトリのルートから実行します。追加ライブラリは不要です。

```powershell
python submissions/2-3.py
python submissions/2-4.py
```

`2-4.py` の出力先は `data/processed/02-data-collection/` です。
データを変更して再提出する場合は、提出用CSVとZIPも更新してください。
