# 課題5-1

## 散布図からの事前予想

squatは分類しやすく、walkとjumpの区別は難しいと予想する。

## 評価用Accuracy

72窓中65窓正解、Accuracyは65/72 ≈ 0.9028（90.28%）だった。

## 予想と結果の比較

squatは評価用20窓すべてを正しく分類でき、分類しやすいという事前予想と一致した。
予想どおりjumpとwalkの間で誤分類が見られ、特に実際はjumpであるものをwalkと認識したパターンが5窓と多かった。
jumpの特徴量は広い範囲に分布しており、walkと重なる領域もあるため、その違いを今回のモデルでは捉えきれなかった可能性があると考える。
