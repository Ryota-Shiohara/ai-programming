# 課題6-4：未知の受講者に対する認識性能

## Subjectの選定理由

解析前にSubject 03・05・06を選んだ。3名とも歩行時は左手持ちで、03と06は端末上部を下に向けていた。また、全員の3動作が各5試行揃い、約30Hzのデータを共通の窓条件で比較できるためである。保持方法や端末の向きはすべての動作で一致しているわけではない。

## 評価方法と結果

Subject 03・05・06のうち1名を評価用に外し、残る2名の窓で標準化と学習を行った。6-1と同じ標準偏差・最大値の2特徴量とロジスティック回帰を用いた。

連続区間は公称30Hzとして扱った。隣接する記録の間隔が2サンプル分以上になった箇所では区間を分け、途切れをまたぐ窓を作らなかった。Subject 03のJump 1、Squat 1、Squat 2に該当箇所があった。補間はしていない。

## 6-1との比較・考察

03と06を評価に用いたときのAccuracyはそれぞれ87.60%と89.05%で、6-1の平均86.47%と同程度か、それを上回った。この2名については、学習に含まれない人にもある程度適用できたと考える。一方、05を評価に用いたときのAccuracyは46.08%と大幅に低く、6-4の平均Accuracyは74.25%、平均Macro F1は0.7324と、いずれも6-1を下回った。Accuracyの標準偏差も5.49ポイントから19.92ポイントに広がっており、未知の人に対する性能は評価対象によって大きく異なった。

05では、実際はwalkだった110窓すべてがsquatと予測された。個人差に加え、スマートフォンの保持方法の違いが影響した可能性がある。05の取得条件ではwalkとsquatはいずれも端末の背面を手のひら側にして左手で持っており、動作ごとの持ち方の違いは記載されていない。一方、03はsquatで左手を肩の高さに維持し、06はsquatで端末を胸の前に両手で持っていた。こうした違いが合成加速度の標準偏差や最大値に表れ、05のwalkとsquatを取り違えた理由の一つになったと考えられる。ただし、保持方法を揃えた比較は行っていないため、今回の結果だけで測定方法と個人差の影響を切り分けることはできない。
