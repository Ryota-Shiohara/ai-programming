# 課題2-5：田植えを模擬した動作のセンシング

## アイデア

手植えの田植えを想定し、「苗を植える」「次の場所へ移動する」「苗を補充する」を識別する。
動作ごとの作業時間を集計し、作業の進み具合や休憩の目安を可視化するサービスを考える。

まず室内で動作を再現して計測する。実際の田んぼでの識別性能は、このデータだけでは確認できない。

## 当初の計測計画（実際の条件は下記参照）

| 英語ラベル | 模擬動作 | ファイル名 |
| --- | --- | --- |
| `plant` | 前かがみになり、手を地面に近づけて苗を植える動作を繰り返す | `plant1.csv` ～ `plant5.csv` |
| `move` | 次の植え付け位置へ移動する想定で、ゆっくり数歩ずつ進む動作を繰り返す | `move1.csv` ～ `move5.csv` |
| `refill` | 手元の苗置き場から苗を取り、作業する手に補充する動作を繰り返す | `refill1.csv` ～ `refill5.csv` |

- サンプリング周波数：30Hzを予定。
- 記録時間：各試行10秒を目安にする。
- 取得回数：各動作5試行を予定。
- 装着場所：腰を候補とし、両手を使えるように固定する。
- 端末の装着場所・画面とトップの向きは、全試行で揃える。
- 各試行は別ファイルで記録し、保存後にファイル名を付ける。
- 記録中は該当する動作だけを行い、別の動作への切り替えは記録の外で行う。

## 保存済みデータ

- `move1.csv` ～ `move5.csv`：移動。英語ラベルは `move`。
- `taue1.csv` ～ `taue5.csv`：田植え。英語ラベルは `plant`。
- 元ファイル `movw1.csv` は、保存時に `move1.csv` へ名前を統一。内容は変更していない。
- 苗の補充（`refill`）のデータは未受領。現在保存済みの動作セットは2種類。
