## 課題4-1

- 元データ：課題2-2の `jump1.csv` 全体。
- 対象：重力分離済み加速度Z軸 `acc_z`。
- 移動平均：中心5サンプル。端は反射パディング。
- メディアン：中心5サンプル。端は反射パディング。
- ローパス：4次Butterworth、カットオフ3Hz、公称サンプリング周波数30Hz。
  `sosfiltfilt` により前後方向へ適用する（オフライン処理）。
- 最上段に元データと3種類のフィルタ結果を重ねた4本のグラフを配置し、下の3段では各フィルタと元データを個別に比較します。全4段の軸範囲は共通です。
- 画像は `output/4-1.png`、比較用数値は `output/4-1-filtered.csv`。
- フィルタ後の小さな振幅が必ず正しいとは限りません。動作由来のピークも減衰する可能性があります。

## 課題4-2

- 提出の対象は `walk1.csv`。4-1のジャンプとは異なる動作です。
- 30Hzの1秒窓を30サンプル、50%重複を15サンプル刻みとして実装。
- 最後の30サンプルに満たない部分は使用しません。試行の境界をまたぎません。
- 元の32列・値・タイムスタンプは保存したままです。
- 元時刻に揺らぎがあるため、先頭と末尾の時刻差が厳密に1秒になるとは限りません。
  30Hzで30点の標準的な窓を使用し、補間・再サンプリングはしていません。
- フィルタも30Hzとみなして適用します。時刻が逆転・重複したり大きく間隔が空いた場合は停止します。
- `--all` で、比較用にWalk / Jump / Squatの全15試行を同じ方法で分割します。
- 保存先：`data/processed/04-preprocessing/windows/`。

## 課題4-3

- 4-2と同じ方法で作った全15試行のウィンドウを使います。
- 各ウィンドウの重力分離済みXYZから合成加速度 `sqrt(X² + Y² + Z²)` を計算。
- 時間領域の特徴量：平均、標準偏差（ddof=0）、最大、最小、RMS、最大−最小の6つ。
- 1行が1ウィンドウ。`label` 列が英語の動作ラベルです。
- `source_file` と `window_id` は出所の記録用で、特徴量には含めません。
- 保存先：`data/processed/04-preprocessing/features.csv`。
- 4-1のフィルタは比較演習のみ。特徴量はフィルタしていない元データの窓から抽出しています。

## 課題4-4

- 提出する特徴量は合成加速度の標準偏差と最大値を選択。
- 比較用の標準偏差とRMSの散布図は、`4-4.py --y-feature rms` で `output/4-4-std-rms.png` に保存します。
- 画像は `output/4-4.png`。1点が1ウィンドウです。
- 最大値は窓内のピーク、標準偏差は平均周りのばらつきです。両者は関連することがあるため、独立した情報を表すとは限りません。
- 元データの装着位置・向きは動作ごとに異なります。動作だけが差の原因とは断定できません。
- 窓は重複しているため、点の数を独立した計測の回数と解釈しません。
- 学習・評価は未実施。将来Train/Testに分ける際は試行単位で先に分割し、各側で窓を作ります。

## 課題4-5（ボーナス）

- `4-3` の表を保持したまま `features-with-frequency.csv` に `fft_peak_hz` 列を追加。
- 元の各30サンプル窓の合成加速度から平均を引き、Hann窓を掛け、実数FFTを計算。
- 0Hzを除く振幅スペクトルが最大の周波数を採用。定数信号は0Hzとする。
- 周波数刻みは `30Hz / 30サンプル = 1Hz`。ゼロ埋めはしない。
- この特徴は最大のスペクトル成分を表すもので、必ずしも動作の基本周波数とは一致しない。
- 時刻の揺らぎは公称30Hzとして扱い、4-2と同じ窓を使用する。
- 比較図は左：追加前の標準偏差×最大値、中央：標準偏差×ピーク周波数、右：3特徴量の3次元散布図。
- 中央の図は最大値を軸から外した投影、右の図は元の2特徴量と新しい周波数特徴をすべて保持。
- 周波数は離散値なので点が重なる。位置をずらしていないため、点がすべて見えるとは限らない。
